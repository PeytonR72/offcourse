# Issue tracker: Local Markdown

The user selected local Markdown tickets. GitHub hosts source code; GitHub Issues is not the ticket tracker.

- Official specification: `docs/OFFCOURSE_SPEC.md`.
- Tickets: `.scratch/offcourse/issues/`, one file per ticket, preserving T01–T18 and the dependency edges from the official spec.
- Read a ticket by its T-number and the official specification before implementing it.
- The `Status:` field tracks triage or completion. Dependencies must be complete before a ticket starts.
- Append implementation evidence, review results, and commit references to the relevant ticket.
- Keep the official specification authoritative; the local spec entry points to it rather than duplicating it.

Formalizing a ticket does not authorize its implementation. See `docs/agents/workflow.md`.
